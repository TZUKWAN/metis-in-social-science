## 🤔 Metis 是什么

社会科学家的一天通常在四类互不连通的工具之间来回切换：文献管理器、PDF 阅读器、
笔记与写作工具，以及一个通用 AI 聊天窗口。代价人尽皆知——**上下文在每个工具边界
手工重建，声明随每次复制粘贴衰减出处，审计轨迹无法穿越工具边界存活**。

与此同时，AI 辅助科研的诚信风险已是可测量的事实：对 ChatGPT 生成参考文献的审计
发现了大量虚构条目；一个声称"做了实验"、引用了任何工具从未产出之数字的智能体，
生产的是**具备论文形状的文本，而非具备论文形状的证据**。

> **Metis 的回答**：把这两件事都变成运行时计算的属性——
> AI 被允许做什么（可执行场景），以及产出是否值得学术信任（强制诚信）。

Metis 是一个**本地优先**的桌面科研工作台：主存储是你自己机器上的 SQLite 数据库，
API 密钥存入操作系统级安全存储；只有当你主动发起模型调用、学术 API 查询或邮件
收取时，数据才会离开你的机器。

## 🎯 两大设计承诺

### 1️⃣ 可执行场景（Executable Scenarios）

研究流程不是一堆提示词，而是**版本化、依赖可解析的配置图**：场景绑定智能体、
技能、MCP 服务、规则文档（Metis.md）、多步工作流、记忆策略与输出契约。

- 会话启动时，场景被编译解析为**冻结的运行清单**（每提示层携带 SHA-256 摘要）
- 正在运行的会话执行冻结清单；**后续编辑只产生未来修订**，绝不悄然改变运行中的任务
- 场景编写由 LLM 辅助，但被**确定性阶段门与信任边界**约束——身份、修订与出处
  字段钉定到持久化定义上，**模型无法重写自己的脚手架**

### 2️⃣ 运行时强制的研究诚信（Runtime-Enforced Integrity）

证据记账、数值声明溯源、参考文献交叉验证、密码学签名的引用收据、九维诚信报告——
全部由**确定性引擎代码**计算。提示词、场景文本或智能体输出**均无法将其关闭**。

| 你掌控的 | Metis 运行时掌控的 |
| --- | --- |
| 研究行为、角色、工作流、工具、记忆、输出、质量标准 | 执行快照、证据账本、来源状态、修订身份、出处、诚信报告 |
| 安装并绑定哪个技能或 MCP | 已安装代码如何注册、观测结果如何记账 |
| 何时引导、停止、编辑、归档、恢复 | 一次运行能否宣称"已验证、已修订、可发布" |

## 🧩 核心功能

### 🎬 可执行场景与 AI 编译器

**对话式构建，逐阶段验收。** 在场景配置助手里用自然语言描述需求，AI 编译器分
五个阶段逐步构建，**每个阶段结束由确定性验收门把关**——不达标立即带着具体问题
返回模型做阶段内修复，而不是攒到最后一次性爆雷：

| 阶段 | 内容 | 确定性验收门（节选） |
| --- | --- | --- |
| 1️⃣ 基础信息 | 名称 · 描述 · 能力 | 名称非空；描述 ≥ 20 字符；能力已设 |
| 2️⃣ 交付物 | 类型 · 篇幅 · 章节 | 类型在允许枚举内；篇幅存在；章节具稳定 id 与标题 |
| 3️⃣ 工作流 | 步骤 · 提示 · 标准 | 非空；每步具稳定 id、名称、专属提示与完成标准 |
| 4️⃣ 规则 | Metis.md 规则层 | 渲染出的规则文档不是空模板 |
| 5️⃣ 输出计划 | 格式 · 产物 · 质量 | 主交付物、支撑产物与质量标准齐备 |

**信任边界**：编译器响应在严格边界解析——身份字段
（`id / kind / contractVersion / revision / provenance`）一律钉定自持久化场景，
Zod 严格校验失败即整单拒绝。

**写作体验**：每个阶段先联网检索资料、再逐条写入；右侧编辑器**实时逐块成型**；
缺失的技能 / MCP 服务由编译器**自动搜索市场、核验安装并绑定到步骤**（全程可见、
可审计、可卸载）；构建结束自动保存，未保存离开会弹窗提醒。

**能力获取有护栏**：市场搜索只读；安装仅限 HTTPS 来源；单次构建安装数量有上限；
安装动作全部进入执行事件流。

![场景 AI 编译](docs/screenshots/ui-journey/j1b-scenario/03-compiled.png)

### 🔬 运行时强制的诚信管线

每次运行结束时，你得到的不是一段"看起来可信"的文本，而是一份**带判定的诚实报告**：

**① 证据账本（EvidenceLedger）**
每次工具调用的输入/输出做 SHA-256 记账，并保留原始 I/O。验证时重算哈希——
事后篡改存储结果可被检出。

**② 自欺守卫（SelfDeceptionGuard）**——四项自动化检查：

| 检查 | 逻辑 | 严重度 |
| --- | --- | --- |
| 🔢 数值声明溯源 | 输出中的数字必须能在工具结果中找到 | ≤2 处警告，>2 处严重 |
| 🧪 实验执行证明 | 声称做了实验，必须有 execute_code 记录 | 违例即严重 |
| 📚 引用真实性 | DOI / arXiv 标识符必须通过元数据交叉验证 | 违例即严重 |
| ⚖️ 自洽性 | 输出内不得自相矛盾 | 警告 |

**③ 引用真实性收据（CitationTruth Receipt）**
引用验证超越"存在性检查"：DOI/arXiv 对照标题、作者、年份交叉验证；来源快照做
规范化摘要；收据以 **HMAC 签名**（密钥存 OS 级保险库）、带存活期（TTL）、常数
时间验证。它断言的是：*在该制品版本中，这些引用在该时刻指向这些已验证来源*——
一份可审计、会过期的凭证。

**④ 九维诚信评分与判定带**

| # | 维度 | 权重 |
| --- | --- | --- |
| 1 | 实验可复现性（已执行代码比率） | 0.11 |
| 2 | 数值声明溯源 | 0.13 |
| 3 | 引用真实性 | 0.13 |
| 4 | 工具调用审计完整性 | 0.09 |
| 5 | LLM 自洽性 | 0.09 |
| 6 | 被引文献撤稿筛查 | 0.13 |
| 7 | 声明出处覆盖率 | 0.07 |
| 8 | 声明对被引来源的忠实度 | 0.13 |
| 9 | 写作/格式质量（表、公式、图） | 0.12 |

综合分 S ∈ [0,100]：**S ≥ 80 通过（绿）· 60 ≤ S < 80 警告（黄）· S < 60 失败（红）**。
权重刻意上调溯源、真实性、撤稿与忠实度——最贴近学术诚信的维度。

> ⚠️ 诚信分是**决策支持而非证明**：绿色判定意味着"没有自动化检查失败"，
> 它引导人工复核，而不是替代人工复核。

**⑤ 不可关闭的运行时层**
硬安全边界（破坏性命令黑名单、抗引号混淆）、能力权限、证据状态、修订与出处
身份——全部由确定性代码计算，**在模型动作空间之外**。

### 🤖 智能体引擎

无框架的 TypeScript 回合制执行核心（刻意不依赖任何智能体框架，让信任边界保持
可审计）：

- **预算化上下文组装**：六档内置预算画像（micro_4k → deep，4K 至 200K token），
  提示不超窗口阈值、工具结果逐条截断
- **语义化溢出恢复**：上下文溢出触发历史激进重压缩并**续跑同一步**，而不是盲目
  重试丢失上下文
- **环路守卫**：相同响应检测（连续 3 轮同签名即干预，工具参数指纹并入签名防误报）、
  会话级工具调用预算、反复修复时温度有界递升
- **硬安全边界**：以破坏性系统变更为目的的命令（递归强删、格式化、关机、强制
  版本控制操作等）经模式分析被拒绝，且**刻意对抗引号混淆**；任何配置都无法关闭
- **人在回路（HITL）**：敏感工具可要求确认；被拦工具进入审批队列，运行暂停直至
  人工决策
- **有界修复环**：工作流步骤的完成标准是强制的——弱输出在当前步内修复而非虚假
  推进；系统上界每步 ≤5 次迭代、失败重试 ≤2 次

### 📚 文献与阅读

- 📥 PDF 导入与**深度阅读**：高亮 + 批注持久化、区域批注、AI 解读选中段落、
  批注一键导出文献笔记、来源更新后高亮标记 STALE
- 🔎 检索集成：**NCPSSD**（中文社科）与 **OpenAlex**（SCI/SSCI），支持核心期刊过滤
- 🏷️ 元数据自动补全：DOI / arXiv ID 一键补全标题、作者、年份、摘要（不覆盖手动编辑）
- 📡 RSS 订阅：arXiv 源自动刷新 + 逐条 AI 中文摘要
- 🔍 Ctrl+K 全文搜索：SQL 级查询论文正文，一键直达
- 📤 导出：BibTeX / CSV / RIS 导入 / 自包含静态网页 / Notion CSV
- 🗂️ 证据锚点：每条证据钉死到来源精确位置（页码 / 字符区间 / 时间戳 / 表格行），
  附引用文本快照与来源版本哈希

### 📝 成果工作台（Word / PPT）

- 应用内编辑 DOCX / PPTX：排版、字体、颜色、表格、图片元素级操作
- 版本历史 + 审核状态流（草稿 → 待审 → 通过）
- **AI 协作**：全文修改与选区局部修改，AI 修改自动存为新版本、可随时回退
- DOCX / PPTX 双向导入导出；导出前过**真实性闸门**（引用必须携带新鲜的真实性
  凭证、数字论断必须有证据绑定、图表引用必须有对应实物——fail-closed）

### 🧠 个人化中心（五类用户自有定义）

开箱即带**五个空定义区**——Metis 不预置任何期刊模板、学科工作流或演示场景：

| 定义类型 | 绑定内容（节选） |
| --- | --- |
| 🎬 场景 scenario | 触发短语；智能体/技能/MCP/规则绑定；多步工作流；记忆范围；输出契约 |
| 🤖 智能体 agent | 角色与系统指令、模型偏好、工具与技能绑定、记忆策略、回合上限 |
| 🛠️ 技能 skill | Markdown 指令 + 可选打包脚本；输入/输出模式字段 |
| 🔌 MCP 服务 | 安装来源、传输方式、命名密钥引用（值永不回传渲染层） |
| 📜 Metis.md 规则 | 全局 / 场景 / 项目三种作用域的规则文档 |

所有类型**保存即产生不可变修订（r+1）**，更早修订随时可恢复；支持按定义图
导入导出配置包（凭据永不导出）。

### 🆓 免费模型中心（实验性）

个体研究者的现实瓶颈是模型访问。Metis 内置一个**批式、限速**的免费模型获取
子系统：在用户显式配置下，于广泛部署的开源 "new-api" 系 OpenAI 兼容网关站上
自动发现、探活、注册（IMAP 收取验证码）、读取额度并铸造令牌。

- 🚦 **定价表门**：模型被列为免费当且仅当定价表明确为零——表外条目一律视为
  未知，**零余额账号绝不会把付费墙后的模型当作免费呈现**
- 📊 调度器每批 5 站、站间 3–5 秒随机延迟，逐站进度流式推送界面
- 🔐 铸出的密钥加密存入密钥保险库
- ⚠️ 依赖第三方服务，明确标注**实验性**；人机验证拦截等结果如实标记为 skipped

## 🏗️ 技术架构

三层桌面架构，**契约先行的 IPC**——每个跨边界载荷都经严格模式校验
（禁止多余键、有界字符串、控制字符拒绝、枚举错误码）：

```
┌─────────────────────────────────────────────────────────┐
│  渲染进程 — React 19 单页应用（沙箱化，无 Node 权限）        │
│  对话 · 文献库 · PDF 阅读 · 笔记 · 成果工作台 · 个人化中心    │
│  24 个顶层页面                                            │
├─────────────────────────────────────────────────────────┤
│  预加载桥 — contextIsolated 白名单 API（约 1,940 行）        │
│  类型化 IPC 面 · 渲染层授权门                               │
├─────────────────────────────────────────────────────────┤
│  Electron 主进程（Node.js）                                │
│  ├─ 功能服务（约 90 个模块）：场景运行协调器 · 安装器 ·        │
│  │   DOCX/PPTX 服务 · 免费模型发现 · 密钥保险库 · 安全导出    │
│  └─ Metis 引擎（无框架 TypeScript 库）                      │
│      AgentLoop · ContextEngine + BudgetManager ·           │
│      EvidenceLedger · IntegrityReporter ·                  │
│      SelfDeceptionGuard · CitationTruth ·                  │
│      场景编译器 + 阶段门 · 工作流/目标引擎 · MCP 管理器        │
├─────────────────────────────────────────────────────────┤
│  持久化：本地 SQLite（better-sqlite3）· OS 密钥保险库 ·        │
│  项目工作区文件（PDF · Metis.md · 导出物）                   │
└─────────────────────────────────────────────────────────┘
```

**实现度量**（发布源码树实测）：

| 预加载桥 preload.ts | 1,940 行 |
| 主进程功能服务模块 | ≈90 |

## 📦 安装

### Windows 安装包（推荐）

1. 前往 [**Releases**](https://github.com/TZUKWAN/metis-in-social-science/releases/latest)
   下载 `Metis-Research-Workbench-Setup-<版本>-x64.exe`
2. 双击安装（可选择自定义安装目录）
3. 首次运行如遇 Windows SmartScreen 提示（安装包未做代码签名），点击
   **「更多信息 → 仍要运行」**

### 首次启动

1. ⚙️ 配置模型服务商：任意 OpenAI 兼容 API（名称 + Base URL + API Key + 模型名）；
   密钥保存后即掩码显示并存入 OS 级保险库，永不回显
2. 📁 创建你的第一个研究项目
3. 💬 开始对话，或到个人化中心构建你的第一个研究场景

```bash
git clone https://github.com/TZUKWAN/metis-in-social-science.git

# 安装依赖
npm install

# 开发模式（Vite 热更新 + Electron）
npm run dev:electron

# 生产构建（typecheck ×4 + 主进程编译 + 渲染端打包 + 原生模块重编译）
npm run build

# 运行测试
npm test

# 类型检查
npm run typecheck

# 打包 Windows 安装程序（NSIS，输出到 release/）
npm run rebuild:electron
npx electron-builder --win nsis
```

> 💡 `better-sqlite3` 是原生模块：开发（Node ABI）与打包（Electron ABI）所需
> 的二进制不同，分别用 `npm run rebuild:node` 与 `npm run rebuild:electron` 切换。

**技术栈**：Electron 41 · React 19 · TypeScript · Vite · better-sqlite3 ·
pdfjs-dist · Zod（全链路运行时契约）· Vitest · electron-builder

## 🗺️ 定位与边界（诚实声明）

**与同类工具的关系（定性，非基准）**：

- **文献管理器（Zotero 等）**：长于目录策展，并非为执行研究流程或计算证据诚信而
  设计——Metis 是其补充而非替代
- **自主"AI 科学家"系统**：证明端到端生成可行，但把诚信当事后补丁；Metis 把诚信
  基底放在首位，并把场景自主性约束在有系统上限的修复环、暂停/取消与审批队列之内
- **通用智能体框架**：提供编排原语，但缺少平台内的学术特化保证（引用收据、撤稿
  筛查、声明清单）

**已知局限**：

1. 无基准评估——报告的是实现度量与记录在案的测试运行，不是任务基准分数
2. 边界处护栏是启发式的——数值溯源基于文本匹配（改写数字可绕过）；硬安全边界
   基于模式（新型破坏性语法需更新黑名单）；纵深防御可缓解但不能根除
3. 诚信分是决策支持而非证明——绿色判定是学术信任的必要而非充分条件
4. 免费模型子系统依赖第三方服务，可选且实验性
5. 当前仅发布 Windows x64；技术栈跨平台，但 macOS/Linux 未经验证
